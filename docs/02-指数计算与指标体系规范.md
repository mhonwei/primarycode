# HSCI 指数计算与指标体系规范（v0.1）

> 本文把 v1.0 方案 §2.3、§3 的思路落实为可编码的定义。所有参数标注"待校准"的，在方法学页公开并纳入 changelog。

## 1. 符号约定

- 危机域 `c ∈ {C1..C10}`，时间层 `t ∈ {T0..T6}`
- 每个有效格子 (c,t) 评估三元组 `(P, I, U)`：
  - `P`：该时段内显著发生的概率（0–1，允许跨数量级）
  - `I`：影响烈度 1–5（1 局部扰动 / 2 区域危机 / 3 全球性危机 / 4 文明崩溃 / 5 物种灭绝）
  - `U`：证据等级 {1 实测数据, 2 模型区间, 3 专家判断}

## 2. 格子分数公式

概率跨越 7 个数量级，先做对数归一：

```
P̂ = clamp( (log₁₀P + 8) / 8 , 0, 1 )      # P=10⁻⁸ → 0，P=1 → 1
R(c,t) = 100 · P̂ · (I/5)^γ                 # γ = 0.7（待校准）
```

- γ < 1 让高烈度事件不被小概率完全抹平（灭绝级事件在图上必须可见，这正是系统的叙事目的）。
- `U` **不参与数值计算**，只驱动视觉表达（§6），避免"不确定就降分"的隐性乐观偏差。

## 4. 域子指数与双综合指数

### 4.1 子指数

```
Sᵢ(t) = R(cᵢ, t)                          # 域 × 时间层分数
Sᵢᴬ = Σₜ λₜ·Sᵢ(t) / Σₜ λₜ                 # 行动视角：时间加权（仅有效格）
Sᵢᴱ = maxₜ Sᵢ(t)                          # 存在视角：无贴现取峰值
```

时间层权重（待校准）：`λ = [1.0, 0.6, 0.35, 0.15, 0.07, 0.03, 0.01]`（T0→T6）。

### 4.2 双综合指数

```
HSCI-A = Σᵢ wᵢ·Sᵢᴬ      # 行动指数：这一代人该多着急（与末日时钟对话）
HSCI-E = Σᵢ wᵢ·Sᵢᴱ      # 存在指数：物种层面的处境（无时间贴现）
```

### 4.3 冷启动权重（文献代理，Phase 1 用）

依据 Ord《The Precipice》世纪存在风险估计与 GCF 年报排序归一化（待校准）：

| 域 | C1 | C2 | C3 | C4 | C5 | C6 | C7 | C8 | C9 | C10 |
|---|---|---|---|---|---|---|---|---|---|---|
| wᵢ | 0.14 | 0.08 | 0.12 | 0.06 | 0.10 | 0.04 | 0.03 | 0.05 | 0.35 | 0.03 |

C9 权重最大直接来自 Ord（AI 1/10 + 工程病原体 1/30 占其 1/6 总估计的大头）——这是 C9 必须默认纳入的原因（见分析文档 D15）。发布时附敏感性分析：所有 wᵢ ±50% 重采样 1000 次，报告 HSCI 的 5–95 分位区间。

## 6. 色带与不确定性视觉规范

### 6.1 风险色带（修订版，明度单调）

| 档 | 区间 | 色值（暗色主题） | OKLab L | 语义 |
|---|---|---|---|---|
| 绿 | 0–25 | `#86d29c` | 0.80 | 可控 |
| 黄 | 25–50 | `#cfa32e` | 0.74 | 关注 |
| 橙 | 50–70 | `#c06a2c` | 0.61 | 警告 |
| 红 | 70–90 | `#a33d38` | 0.50 | 危机 |
| 黑 | 90–100 | `#2a1626` + 警示描边 `#ff5a4d` | 0.24 | 生存威胁 |

明度严格单调递减 → 色盲与灰度场景下排序仍可读。黑档在暗色背景上加 1.5px 警示描边防止消失。

### 6.2 不确定性编码

| U | 判据 | 视觉 |
|---|---|---|
| 1 实测 | 连续观测序列 | 实色 |
| 2 模型 | 同行评审模型区间 | 饱和度 -30% |
| 3 判断 | 专家估计/单一文献 | 饱和度 -30% + 45° 斜线纹理 |

纹理（而非仅透明度）保证投影、打印、forced-colors 模式下可辨。每格悬停显示 P/I/U 原始值与来源。

## 7. 发布与治理

- 指数按**年度**正式发布（与末日时钟节奏对齐），Tier A 数据月度刷新只更新子指标展示、不改年度指数值。
- 任何公式/权重/锚点变更 → 方法学 changelog 记录 + 历史序列重算 + 图上标注方法学断点。
- 首页免责声明（固定文案）："HSCI 是风险沟通与教育工具，表达的是文献与数据支持的风险量级与方向，不是对未来的预测。"
