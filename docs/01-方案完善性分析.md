# HSCI 方案完善性分析（针对讨论稿 v1.0）

> 结论先行：v1.0 的**概念框架是完整且高质量的**——二维矩阵（危机域 × 时间地平线）作为骨架、深时叙事作为灵魂、传播伦理作为红线，这三点都站得住。但它是一份"愿景书"，距离可实施还缺一层"规范书"：**指数如何算、数据如何真的拿到、70 个矩阵格哪些有效、情景模拟器背后的模型是什么**——这四个问题不回答，Phase 0 之后就会卡死。本文逐项分析缺口并给出补充方案，详细规范见 `02-指数计算与指标体系规范.md` 和 `03-数据管线设计.md`。

## 一、v1.0 已经完善的部分（不再改动）

- 系统定位与"末日时钟互补"的叙事关系（§1）
- C1–C10 × T0–T6 的二维矩阵骨架（§2）
- P / I / U 三量评估的思路（§2.3）
- 数据可溯源、不确定性显式表达的学术底线（§3.4、§7）
- 七视图的产品愿景与四阶段路线图（§5、§8）

## 二、缺口清单与补充方案

### A. 方法论层（最关键，直接决定系统可信度）

**A1. P/I/U 如何合成为一个格子分数——公式缺失。**
v1.0 说每格评估三个量，但没有说三个量怎么变成热力图上的一个颜色。概率横跨 7 个数量级（小行星 10⁻⁶/世纪 vs 升温超 2°C 接近确定），线性合成会让低概率高烈度事件在图上完全消失。
→ **补充**：格子分数采用对数概率分 × 烈度幂函数，`R = 100 · P̂ · (I/5)^γ`，其中 P̂ 是对数尺度归一化的概率分。完整公式与参数见规范 02 §2。

**A2. 时间贴现 λ 有伦理陷阱。**
v1.0 §3.1 提出"近期危机权重高于远期（贴现系数 λ）"。但存在性风险学界（Parfit、Ord）的核心论点恰恰是**对灭绝风险不应做时间贴现**——贴现意味着百万年后的人类不重要，这与本系统"为百万年后的自己负责"的叙事自相矛盾。
→ **补充**：发布**双指数**而非单指数：
- **HSCI-A（行动指数）**：带时间贴现，回答"这一代人该多着急"，与末日时钟对话；
- **HSCI-E（存在指数）**：无贴现，各时间层取最大风险，回答"人类这个物种处境如何"。
两个数字并列展示，本身就是一次深时教育。

**A3. 权重 wᵢ 的"德尔菲法"在项目初期不可行。**
两轮德尔菲需要一个真实的专家小组，个人/小团队项目冷启动阶段拿不到。
→ **补充**：三阶段权重演进：Phase 1 用**文献代理权重**（Ord《The Precipice》的存在风险概率表 + Global Challenges Foundation 年报的风险排序，可直接引用、可被检验），并发布权重敏感性分析（权重 ±50% 时综合指数的波动范围）；Phase 2 起再引入外部专家意见；德尔菲作为长期目标保留。

**A4. 指标层完全缺失。**
子指数 Sᵢ"由若干可溯源指标加权合成"，但没有任何一个域给出指标清单和归一化方法（CO₂ 的 420 ppm 怎么变成 0–100 分？）。
→ **补充**：规范 02 §4 给出十个域的**指标字典**（每域 3–6 个指标、来源、归一化锚点）。归一化统一采用"三锚点法"：安全基线（如前工业 280 ppm）→ 政策目标（如 450 ppm）→ 危险阈值（如 550 ppm），分段线性映射到 0/50/100。

**A5. 矩阵稀疏性：70 格并非都有意义。**
"环境污染 × 百万年"、"太阳膨胀 × 当下 30 年"这类格子没有科学内容。全部填色会制造伪信息。
→ **补充**：定义**有效性掩码**（规范 02 §3），无效格显式标记 N/A 并在视觉上留空/划斜线，这是"不伪精确"底线的直接落实。约 70 格中有效格 46 个。

**A6. 不确定性 U 缺量化标准。**
"高/中/低"三级没有判据，评估者之间无法一致。
→ **补充**：按证据类型定级——**实测数据**（连续观测序列，如 Mauna Loa CO₂）= 高共识；**模型区间**（IPCC 情景类）= 中；**专家判断**（AI 失控概率类）= 低。视觉编码：实色 / 降饱和 / 斜线纹理（不只靠"雾化"透明度，照顾投影与打印场景）。

### B. 数据层

**B7. 数据源"可自动更新"是过度承诺。**
§4 清单里的源可行性差异极大：SIPRI 年鉴是 PDF、IPCC 报告没有 API、IUCN 红色名录 API 需申请且有许可限制、末日时钟只是每年一篇新闻稿。按 v1.0 的写法去搭管线，会发现一半的源根本抓不到。
→ **补充**：数据源按获取方式分三档（规范 03 §1）：**Tier A 可自动抓取**（NASA CNEOS、NOAA、Scripps CO₂ CSV、USGS 地震流）；**Tier B 年度人工录入**（SIPRI、UN WPP、IUCN 汇总数、末日时钟秒数）；**Tier C 静态文献常数**（Ord 概率、超级火山复现周期、太阳演化时间表）。前端溯源标注同时显示档位，用户能看出哪些数字是"活的"。

**B8. 数据 schema、版本化、失效降级未定义。**
→ **补充**：规范 03 §2 定义快照 JSON schema（每个指标带 `value / unit / source / retrieved_at / tier / license`）；管线失败时前端显示上一次快照并标注"数据截至 X 日"，绝不静默展示过期数据。指数每次重算生成带版本号的快照，历史快照即 §6 所说的"HSCI 年度曲线"研究资产。

### C. 产品与可视化层

**C9. V7 情景模拟器是最大的技术黑洞。**
"拖动滑杆、指数实时重算"需要一个因果模型：CO₂ 路径 → 升温 → 各域风险。v1.0 完全没有说这个模型从哪来。真做 FaIR 级气候模型不现实，瞎做会毁掉学术公信力。
→ **补充**：明确 V7 使用**简化教学响应函数**（如 TCRE 线性关系：每千吨碳 ≈ 0.00045°C，核弹头数 → 核冬天烈度分档），并在界面上永久标注"教学模型，展示因果方向与量级，非预测工具"。这既能实现交互体验，又守住 §7 的学术底线。V7 从 Phase 2 移到 Phase 3。

**C10. V6 级联推演的边数据无来源。**
桑基图的每条边（气候→粮食→冲突）需要关系强度数据。
→ **补充**：建立**级联边表**（规范 03 §3）：每条边 = {源域, 目标域, 机制描述, 文献引用, 强度分 1–3}，初版从 IPCC AR6 WGII、Richards et al. (2021) 级联失效文献人工编码约 20 条边。桑基图改为"文献支持的级联路径图"，边宽 = 强度分，点击边显示引用。

**C11. 色带的可访问性缺陷。**
绿→红色带对约 8% 的男性（红绿色盲）不友好，且五个色档若明度不单调，热力图在灰度打印/投影下不可读。
→ **补充**：重设计色带为**明度严格单调递减**序列（OKLab L: 0.80→0.74→0.61→0.50→0.24，已通过校验脚本验证），色盲用户至少能按深浅读出风险排序；"黑档"在暗色主题上配警示描边以免消失；所有格子悬停显示数值，图例带文字语义。

**C12. 七个视图对路线图而言过重，缺 MVP 裁剪。**
→ **补充**：Phase 0 只做 **V3 热力矩阵 + V2 深时时间轴**（本仓库 `prototype/index.html` 已实现）——这两个视图组合已经能完整传达系统的核心论点。V1 星图（Three.js）观赏性最强但信息密度最低，移动端性能风险大，移到 Phase 2 且需提供 2D 降级方案。调整后：Phase 0 = V3+V2 → Phase 1 = 数据管线+V4+V5 → Phase 2 = V1+V6 → Phase 3 = V7+双语+部署。

**C13. 缺信息架构与综合指数的语义解释。**
"HSCI = 62"对公众是无意义的数字；且缺页面结构/路由设计。
→ **补充**：每个指数值必须伴随三件套：**色带语义词**（如"橙·警告"）、**同比变化**（较去年 +3）、**主要驱动项**（"本期上升主要来自 C3 核战争域"）。信息架构：首页（双指数 + 矩阵）→ 域详情页（/domain/c1）→ 方法学页（/methodology）→ 时间轴页（/deep-time）。

### D. 治理与伦理层

**D14. 缺"方法学透明度"的制度设计。**
一个自创的"人类生存指数"最大的风险是被批为伪科学。v1.0 有学术底线的姿态，但没有制度载体。
→ **补充**：(1) 独立的**方法学页**，公开全部公式、权重、指标锚点与引用；(2) **方法学 changelog**——任何公式或权重变更都留痕并注明对历史指数值的影响（重算历史序列，标注方法学断点）；(3) 首页永久免责声明："本指数是风险沟通工具，不是预测"。

**D15. C9 技术风险域：建议默认纳入，而非可选。**
v1.0 把 C9 留给用户确认。但校准锚点 Ord 的 1/6 世纪风险估计中，AI 与工程病原体**占绝对大头**——如果剔除 C9，综合指数与自己引用的文献锚点直接矛盾，HSCI-E 会严重失真。
→ **建议**：默认纳入 C9，用 A6 的"低共识"视觉语言明确标注其争议性；提供"仅自然与传统风险"的过滤视图作为替代，而不是从指数中剔除。

## 三、缺口影响优先级

| 优先级 | 缺口 | 不解决的后果 |
|---|---|---|
| 阻塞 Phase 0 | A1 公式、A5 掩码、C11 色带 | 热力矩阵画不出来或画出来是错的 |
| 阻塞 Phase 1 | A3 权重冷启动、A4 指标字典、B7/B8 数据分档与 schema | 管线搭一半发现源抓不到、指数算不出 |
| 阻塞可信度 | A2 双指数、A6 不确定性判据、D14 方法学页、D15 C9 决策 | 被学术圈批评后难以翻身 |
| 阻塞 Phase 2+ | C9 模拟器模型、C10 级联边表、C12 裁剪 | 后期返工 |

以上补充已在规范 02、03 中落实为可执行定义；Phase 0 原型见 `prototype/index.html`。
