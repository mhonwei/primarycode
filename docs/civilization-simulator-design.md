# 人类文明发展模拟器：可行性评估与设计方案

**版本** v0.1 · **日期** 2026-07-26 · **状态** 设计已确认，待进入 M0 实现

---

## 执行摘要

本文档评估"构建一个基于过去一万年人类文明发展轨迹、用于预测未来文明演化方向的模拟器"的可行性，并给出完整设计方案。

**核心结论：作为"预测器"不可行；作为"约束式情景生成器 + 分叉点识别器"可行，且有真实价值。**

这不是措辞上的退让，而是决定整个架构的前提。如果目标定为"输出 2100 年某国 GDP 是多少"，项目必然失败，并且会以一种危险的方式失败——它会输出一个精确的数字，而这个数字的精度完全来自参数选择而非世界的结构。如果目标定为"在给定的物理、人口、资本存量约束下，哪些未来路径是可能的、哪些被排除了、系统在哪些时点对小扰动最敏感"，那么这是一个有明确成功标准、可以证伪的工程问题。

项目价值的两个支点：

1. **硬结论**——诚实划出"哪些未来在物理和会计上是不可能的"。这不需要预测能力，只需要守恒律和资本存量的折旧时钟。
2. **真洞察**——指出系统在哪里对扰动最敏感、在哪些时点面临分叉。这同样不需要预测能力，只需要正确的耦合结构和敏感性分析。

把成功标准定在这里，项目可行；定在"预测未来"，它一定会变成一个精致的占卜工具。

# 第一部分：难度与可行性评估

## 1. 学术先例的经验教训

这个领域已有五十年的尝试，失败模式非常清晰。任何新系统若不吸收这些教训，只会重复它们。

| 先例 | 做对的 | 失败的 | 教训 |
|---|---|---|---|
| **World3 / 增长的极限** (1972) | 抓住了存量-流量结构和延迟反馈；2020 年前实际轨迹大致落在其 BAU 区间内（Herrington 2021 复核） | 无价格机制、无内生技术、无空间维度、无国家主体 | 聚合模型可能碰对趋势但机制是错的——**碰对不等于有预测力** |
| **IPCC SSP / IAMs**（IMAGE, MESSAGE, GCAM, REMIND） | 最成熟的社会-技术-气候耦合模型族；情景框架设计优秀 | 连续二十年系统性低估光伏成本下降（已被公开承认） | 处于学习曲线上的技术几乎必然被线性外推低估；这类模型的自我定位就是"情景"而非"预测" |
| **DICE / RICE**（Nordhaus） | 极简、可解、透明 | 损害函数的函数形式与参数近乎凭空设定 | 简洁性的代价是把最不确定的东西压缩进一个参数 |
| **Cliodynamics / Seshat**（Turchin） | 唯一认真处理长周期社会-政治动力学的框架；2010 年对 2020 年代美国不稳定上升的预判方向正确 | 有效样本量极小；"精英过剩"等构念的操作化存在很大研究者自由度 | 长周期社会机制值得建模，但极易事后合理化 |
| **Artificial Anasazi**（ABM） | 唯一被严肃回测的考古主体模型 | 回测发现其拟合严重依赖强加的外生约束 | **ABM 能拟合任何东西，因此几乎不可证伪**——本项目最需警惕的陷阱 |
| **GDELT / ICEWS 冲突预测** | 1–6 个月窗口内有真实、可度量的技能 | 超过 2 年基本无技能 | 冲突的**时点**不可预测，只有**风险水平**可预测 |
| **Tetlock 超级预测研究** | 建立了预测技能的度量标准与人类基准 | 领域专家在 5 年以上地缘政治问题上的技能接近于零 | 这是对本项目最硬的经验约束：长期具体事件预测跑不赢基础率 |

## 2. 困难的真正来源

工程量大是次要问题。真正的障碍有六个，按严重程度排序：

### 2.1 参数不可识别 —— 最根本的障碍

过去一万年不是"一万年的数据"，而是**一条样本路径**。我们观察到的是 N=1 的实现，却想估计一个高维动力系统的参数。有效自由度极低，而模型参数会有数百个。

直接后果：任何足够复杂的模型都能完美拟合历史，**而拟合优度不携带任何关于预测力的信息**。这是本项目最容易死掉的地方，也是 §7 参数预算纪律存在的理由。

### 2.2 非平稳性 —— 机制本身在变

马尔萨斯机制在 1800 年前主导人口-收入关系，之后失效。人口转变理论从欧洲外推到东亚产生了系统性误差（东亚生育率下降远快于模型预测）。用 1950–2020 数据校准的参数不保证 2050 年仍成立。

这不是噪声问题，是结构问题——它意味着历史数据的用途必须重新定义（见 §4）。

### 2.3 重尾主导 —— 均值无意义

战争死亡人数、疫情规模、技术突破的经济影响都近似幂律分布，尾部指数常常使方差不收敛。对这类量做"期望值预测"在数学上就不合法。

直接后果：只能输出分位数与尾部条件期望（CVaR），不能输出均值或"最可能曲线"。

### 2.4 自反性 / Lucas 批判

如果模拟器具有影响力，决策者会对其输出作出反应，从而改变被建模的行为方程本身。这在气候政策领域已真实发生——IAM 生成的情景反过来塑造了政策目标，进而改变了情景的前提。

### 2.5 计算不可约性

即使模型结构完全正确，对强非线性耦合系统，也可能不存在比"运行系统本身"更快的求解捷径。这为长视野下的可解性设置了上界。

### 2.6 后见之明泄漏 —— 最隐蔽的一个

设计者在构建模型时已经知道 1990–2020 发生了什么。这个知识会通过模型结构的选择（加入哪个反馈、采用什么函数形式、保留哪个机制）泄漏进"回测"，让回测结果虚假地好。

**几乎所有同类项目都没有处理这一点。** 唯一的缓解手段是在查看 hold-out 结果之前冻结模型结构与参数先验（预注册），并记录之后的每一次修改及其时序。见 §7.7。

## 3. 可行的真正来源

反过来，有四类东西是硬的，构成项目的价值基础：

### 3.1 人口惯性

2060 年 40 岁以上的人现在都已出生。队列组分法在 30–40 年窗口内是本项目中预测力最强的部分，且能大幅跑赢朴素基线。中国、日本、韩国、欧洲的劳动力萎缩曲线基本已经锁定，剩余不确定性主要来自生育率与迁移假设，而非结构。

### 3.2 守恒律

质量、能量、碳、货币（存量-流量一致会计）。这些本身不产生预测，但**排除**大量不可能路径——例如任何"能源需求翻倍同时化石燃料快速退役"的情景，必须给出对应的产能建设速率，而建设速率受限于水泥、钢、铜的物质流上限。

这类约束是本项目最可靠的输出，且不依赖任何行为假设。

### 3.3 资本存量的折旧时钟

一座燃煤电厂寿命约 40 年，一条高铁 60 年，一套城市管网 80 年。基础设施的替换周期给出了转型速度的物理上界，这是可计算的、近乎确定的约束。

### 3.4 尺度律与稳健经验规律

Kaya 恒等式、Wright 学习曲线、城市规模的 Zipf 分布、能源强度的倒 U 型曲线、人口转变的次序性。这些不是理论假说，是跨时空稳健的经验规律，可作为结构验证的靶子。

## 4. 一万年历史数据的正确用法

这是全设计中最关键的认识论判断，直接来自 §2.2 的非平稳性问题：

**不要用长时段数据拟合预测未来的参数。** 结构已经改变，1800 年前的机制对 2050 年无效，且 1800 年前的 GDP／人口数据本身是模型推算（Maddison、HYDE）而非观测，用推算数据校准参数构成循环论证。

**要用它提取三样东西：**

1. **不变量与尺度律**——城市规模分布、能量投入与社会复杂度的收益递减关系、帝国规模分布、战争烈度的幂律指数、人口转变的普遍形态。
2. **可能性空间的边界**——历史上从未突破的比率（人均能耗上限、国家财政汲取率上限、精英占比与崩溃的经验关系），作为模型合理性的护栏。
3. **结构验证集**——模型必须能自发涌现出这些风格化事实（stylized facts），否则结构就是错的。这是模式导向验证（Pattern-Oriented Modeling）的核心思想：不要求点拟合，要求机制能生成正确的定性模式。

## 5. 分变量可行性评级

这是全文最有实操价值的一张表。**不同变量的可预测性相差数个数量级，模型必须分别对待、分别标注。**

| 变量 | 可信视野 | 能否跑赢朴素基线 | 说明 |
|---|---|---|---|
| 年龄结构、劳动力规模 | 2060 | **能，且优势明显** | 队列惯性，最强项 |
| 总人口 | 2080 | 能 | 生育率假设是主要不确定源 |
| 城市化率 | 2060 | 能 | S 曲线极稳定 |
| 一次能源需求 | 2050 | 能 | 收入弹性 + 效率趋势 |
| 累积碳排 → 温升 | 2100 | 能（物理部分） | 碳循环与气候响应是物理；排放路径才是难点 |
| 电力结构 | 2040 | 勉强 | 学习曲线方向对，速率会错 |
| 人均 GDP 增长率 | — | **几乎不能** | 跑赢随机游走是宏观经济学著名未解难题，不应假装能做到 |
| 国家制度轨迹 | 2035 | 勉强，仅作为风险水平 | 只能给 hazard rate，不能给事件 |
| 战争爆发时点 | — | **不能** | 只能给条件风险与基础率 |
| 技术突破时点 | — | **不能** | 只能给扩散速率的条件分布 |
| 汇率、金融危机 | — | **不能** | 明确排除，不建模 |

**设计上的直接后果：模型必须给每条输出打上可信度标签，并在超出可信视野后自动切换为"探索性"标注。**

## 6. 难度评分

| 目标 | 难度 | 说明 |
|---|---|---|
| 让它跑起来 | 中等 | 3–6 周可有可运行骨架 |
| 守恒律自洽、数据可追溯 | 中高 | 纪律问题，不是聪明问题 |
| 严格 hold-out 回测跑赢朴素基线 | 高 | 对 §5 表格下半部分变量为**不可能** |
| 长期输出可信 | 不可能 | 只能做到"可审计的推理链 + 诚实的不确定性" |

# 第二部分：设计方案

## 7. 系统定位

> 一个**存量-流量一致的、区域化的、显式处理不确定性的文明动力学情景引擎**。
>
> 它的产品不是一条曲线，而是：
> 1. 概率扇形（分位数，非均值）
> 2. 被物理／会计约束排除的路径集合
> 3. 系统的分叉点与敏感性图谱
> 4. 每条结论可追溯到机制链与数据分级的审计记录

## 8. 分层架构

采用**混合模型**：底层是不会说谎的会计骨架，上层是有限理性的决策主体，中间用价格和约束耦合。

- 不用纯 ABM——不可证伪（见 §1 Artificial Anasazi 教训）
- 不用纯聚合系统动力学——回答不了国别问题
- 机器学习仅用于参数估计与代理模型，**绝不用于外推**（训练分布外外推是本类问题最大陷阱）

```
L6  冲击层     重尾随机发生器：战争、疫情、极端气候、金融危机、技术突破、领导人更替
                 └ 输出：外生冲击序列（Monte Carlo 抽样）
L5  地缘层     权力分布、联盟、贸易依赖、军备竞赛、冲突 hazard、国际制度强度
L4  社会政治层  国家能力、合法性、不平等、精英过剩、制度质量、内乱风险
L3  技术层     技术存量、Wright 学习曲线、S 型扩散、R&D 内生投入、跨国吸收能力
L2  经济层     多部门生产、资本存量、能源作为生产要素、贸易网络、SFC 金融账户
L1  人口层     年龄-性别队列、内生生育率、死亡率、迁移（推拉 + 距离 + 侨民网络）
L0  生物物理层  碳循环 + 能量平衡气候、土地、水、可耕地、矿产存量（含品位递减）、生态
```

### 8.1 层间耦合（双向）

关键反馈环：

| 路径 | 机制 |
|---|---|
| `L0 → L1` | 气候损害 → 死亡率、可耕地 → 粮食 → 迁移压力 |
| `L1 → L2` | 劳动力供给、抚养比 → 储蓄率、需求结构 |
| `L2 → L0` | 能源使用 → 排放 → 气候 |
| `L2 → L4` | 增长与分配 → 不平等 → 合法性 |
| `L4 → L2` | 国家能力 → 投资效率、公共品供给 |
| `L4 → L5` | 内部压力 → 对外转移倾向（转移视线假说；有实证基础但效应量小，不可过度依赖） |
| `L5 → L2` | 制裁、贸易断裂、军费挤出 |
| `L3 → 全部` | 技术是最大的横向耦合项 |

## 9. 三个非常规设计决定

### 9.1 能源进入生产函数，不作为成本份额

主流增长模型中能源仅占 GDP 的 5–8%，因此常被当作可忽略项。这在能源充裕时无害，在转型期是错的——它无法解释能源冲击的实际宏观影响量级。

本模型将能源（更准确地说是**有效功 / exergy**）作为独立生产要素，与资本、劳动一起进入嵌套 CES 生产函数。这条路线有 Ayres-Warr 的实证支持，且是本模型区别于标准 IAM 的核心特征之一。

### 9.2 重要人物 = 方差放大器，不是趋势决定项

个体不改变系统的吸引子，但在系统接近临界时决定落入哪个吸引子。

**实现方式：** 定义制度约束度 `C ∈ [0,1]`（权力集中度、任期约束、否决点数量的函数），领导人冲击的幅度按下式缩放：

```
σ_leader ∝ (1 − C) × 系统临界度
```

其中系统临界度是不平等、合法性、财政压力的合成函数。

**实证锚点：** Jones & Olken (QJE 2005) 利用领导人意外死亡的自然实验发现，领导人更替对增长率的影响**在专制国家显著、在民主国家不显著**，效应量级约 ±1.5 个百分点。这给了传导系数一个可校准的经验值。

这样处理使"关键人物影响"成为**可校准、可证伪的方差调制机制**，而不是"如果出现一个曼德拉会怎样"这类无法验证的叙事。

### 9.3 输出永远是分布，尾部单独建模

所有参数是分布而非点值。重尾变量（战争、疫情）使用显式的幂律／次指数分布抽样，绝不使用正态分布。输出报告分位数与尾部条件期望（CVaR），**不报告均值，不生成单条"最可能"曲线**。

## 10. 数据层

| 域 | 主要来源 | 分级 |
|---|---|---|
| 长期 GDP / 人口 | Maddison Project, HYDE 3.3 | 1800 前多为 C 级 |
| 现代人口 | UN WPP 2024 | A |
| 经济 | World Bank WDI, Penn World Table 10 | A / B |
| 能源 | IEA, Ember, Energy Institute Statistical Review | A |
| 气候 | IPCC AR6, FaIR / MAGICC 简化响应, CMIP6 | A（物理）/ B（损害） |
| 制度 | V-Dem, Polity5 | B（编码者偏差） |
| 冲突 | UCDP/PRIO, Correlates of War | B（定义不一致） |
| 不平等 | WID.world, SWIID | B |
| 贸易 | BACI/CEPII, UN Comtrade | A / B |
| 矿产 | USGS, S&P | B |
| 长时段社会结构 | Seshat Global History Databank | C |
| 综合汇聚 | Our World in Data | 继承上游 |

### 10.1 数据分级制度（强制）

所有数据必须携带分级元数据：

- **A 级**：直接观测
- **B 级**：统计估算
- **C 级**：模型推断

**任何模型输出必须能报告"这条结论依赖多少 C 级数据"。** 1800 年前的 GDP 数字全部是 C 级，用它们校准的参数不能主张精度。

## 11. 验证协议 —— 项目的生死线

没有这一节，前面所有内容都只是"用参数讲故事"。

### 11.1 严格时间 hold-out

用 1900–1980 校准，预测 1980–2020。**绝不允许**用 1950–2020 校准再"回测" 1950–2020——那是拟合，不是预测。

### 11.2 基线竞赛（强制）

每个变量必须对比以下基线：

- 随机游走
- 线性外推
- AR(1)
- "最近 10 年趋势延续"
- 领域标准参考（人口用 UN WPP 中位数；能源用 IEA 参考情景）

**跑不赢基线的变量，模型对它没有增加信息，必须在输出中明确声明这一点，而不是悄悄保留。**

预期结果：人口、能源、城市化会赢；人均 GDP 增长率会输。这个结果本身要如实报告。

### 11.3 留出国家交叉验证

在 100 个国家上校准，在留出的 50 个国家上测试。检验参数是普适的还是被拟合的。

### 11.4 结构断点压力测试

- 从 1900 年起点，模型能预测出二战后的秩序转变吗？
- 从 1975 年起点，能预测出中国的转向吗？

**几乎肯定不能。** 这个失败必须被记录并公开在文档中——它定义了模型的能力边界，是诚实性的一部分而非缺陷。

### 11.5 已知失败案例库

维护一个案例库，每个案例记录：模型是否捕捉到、为什么没有、这揭示了哪个机制缺失。

初始案例：苏联解体、中国改革开放、日本长期停滞、光伏成本崩塌、东亚生育率断崖、阿拉伯之春。

### 11.6 参数预算

硬性规定：自由参数数量相对有效独立数据点必须有明确预算，超预算即必须削减机制。

**宁可模型简单到解释不了细节，也不要复杂到无法证伪。**

### 11.7 预注册（对抗后见之明泄漏）

模型结构与参数先验必须在查看 hold-out 结果**之前**冻结并提交至版本控制。之后的每一次修改记录在 `docs/model-changelog.md`，并明确标注该修改是否发生在看过结果之后。

这是对抗 §2.6 所述泄漏的唯一有效手段。

### 11.8 模式导向验证

模型必须自发涌现以下风格化事实，否则结构判定为错误：

- 人口转变的次序性
- 能源阶梯（传统生物质 → 煤 → 油气 → 电气化）
- 战争烈度的幂律分布及其指数区间
- 城市规模的 Zipf 分布
- 能源强度的倒 U 型曲线
- 帝国／国家规模分布

## 12. 技术栈

| 组件 | 选择 | 理由 |
|---|---|---|
| 核心数值 | Python + NumPy，热点用 JAX | 向量化 Monte Carlo；自动微分直接给出敏感性分析 |
| 数据层 | DuckDB + Parquet | 列式、可嵌入；所有数据带来源与分级元数据 |
| 配置与情景 | Pydantic + YAML | 情景即声明式配置，可 diff、可版本控制 |
| 测试 | pytest | 守恒律测试：每步验证质量／能量／碳／货币平衡，误差超阈值即失败 |
| 校准 | 贝叶斯（NumPyro / BlackJAX）+ SALib 敏感性分析 | 参数是分布不是点值 |
| 可视化 | Plotly / Altair | 概率扇形、能源桑基、地缘网络、轨迹聚类 |
| 可复现性 | 固定随机种子 + 数据快照哈希 + 每次运行存 provenance | 结论可审计 |

## 13. 里程碑

| 阶段 | 内容 | 出口标准 |
|---|---|---|
| **M0** | 仓库骨架、SFC 会计内核、数据管道、单区域人口 + 经济、回测框架 | 守恒律测试全绿；跑通 1950→2020 单区域回测；产出第一张概率扇形图 |
| **M1** | L0 生物物理 + L1 人口完整化（队列、内生生育率、迁移） | 人口预测跑赢朴素基线；与 UN WPP 中位情景的偏差可机制性解释 |
| **M2** | L2 经济 + L3 技术；能源进入生产函数；多区域（约 30 单元） | Kaya 分解自洽；能源需求回测跑赢基线 |
| **M3** | 空间细化到国家级（地缘关键国家）；贸易网络 | 留出国家交叉验证通过 |
| **M4** | L4 社会政治 + L5 地缘 | 冲突 hazard 校准至 UCDP 基础率；诚实报告"只有风险水平、没有时点" |
| **M5** | L6 冲击层、情景树、AI / GPT 冲击模块 | 完整不确定性传播；尾部风险（CVaR）报告 |
| **M6** | 可视化、审计追踪、结论生成 | 每条结论可展开查看机制链与数据分级 |

**M0–M1 是"能不能做成"的判据。若 M1 打不赢基线，应停下重新设计，而不是继续叠加复杂度。**

## 14. 明确的"永远做不到"清单

必须写入 README 并在输出界面提示，否则使用者会误用：

1. 不预测任何事件的**时点**（战争、危机、技术突破）
2. 不预测汇率、股价或任何金融资产价格
3. 不预测具体政权更替
4. 不预测 2060 年后的具体数值（只给方向与约束）
5. 不预测尚未存在的技术范式
6. 不主张自身机制是"真实的"——只主张它与数据一致且受守恒律约束

## 15. 三个已识别的风险

1. **复杂度陷阱**——耦合子系统越多，误差传播越快，可解释性越差。World3 与 IFs 的共同教训是"更复杂 ≠ 更准"。**纪律：每个新子系统必须证明它改善了 hold-out 记分才准合入。**
2. **AI 是当前最大的不确定源**——它同时冲击 TFP、就业、军事平衡、信息生态四条链，还可能改变"知识增长速率"这一 Popper 障碍的核心变量。不能按普通技术处理，见 §16.3。
3. **误用风险**——这类模型的输出极易被当作权威预言引用。**缓解：输出层强制携带可信年限、分位数与模型分歧度；禁止生成单条"最可能"曲线。**

# 第三部分：已确认的关键决策

以下四项已在设计讨论中确认。

## 16.1 时间视野：2100，分层标注可信度

采用 2100 作为主视野，但按变量分层标注可信年限：

- 人口相关 → 2080
- 能源与气候 → 2050 / 2100（物理部分更长）
- 地缘政治 → 2035
- 超出部分自动标注为**探索性**，不作为预测呈现

**理由：** 人口队列、基建折旧、气候滞后三个时钟都在 75 年内闭合，2100 是可验证性与洞察力的最佳平衡点，且与 SSP/IPCC 生态数据对齐。

## 16.2 空间粒度：渐进式，30 单元 → 国家级

- M0–M2：约 30 个单元（G20 单列 + 其余区域聚合），用于验证内核
- M3 起：对地缘关键国家细化到国家级

**理由：** 直接建模 200 国会使参数在小国数据噪声上失去可识别性，且 Monte Carlo 成本高一个数量级。渐进路线风险最低，且能最早拿到回测结果。

## 16.3 AI / 通用目的技术冲击：显式模块 + 多情景分支

建模四条传导链：

1. 全要素生产率（TFP）
2. 劳动替代弹性
3. 军事平衡
4. 信息生态

用 3–4 条外生情景分支（缓慢扩散 / 快速自动化 / 能力跃迁 / 停滞），**不假装能预测时点**。

**明确反对**做内生递归反馈环（AI 加速 R&D 从而加速 AI）：它无法校准，且会主导全部输出，把整个模型变成一个关于 AI 假设的复杂放大器。

## 16.4 首轮交付：M0 可运行骨架

优先让"守恒律 + 数据管道 + 回测框架"三件事跑起来，而非先写完美的设计文档。

**理由：** 第一张概率扇形图出来之后，很多设计争论会自动消解。骨架能最快暴露真问题。
