# HSCI 数据管线设计（v0.1）

> 修正 v1.0 §4"全部可自动更新"的过度承诺：数据源按真实可获取性分三档，schema 统一，失效降级显式化。

## 1. 数据源可行性核查与分档

**Tier A — 可自动抓取**（有稳定 API / 静态 CSV，定时任务处理）

| 源 | 内容 | 接口形式 | 频率 | 许可 |
|---|---|---|---|---|
| Scripps CO₂ (Mauna Loa) | CO₂ 浓度 | 静态 CSV URL | 月 | CC BY |
| NASA GISTEMP | 全球温度距平 | 静态 CSV/TXT | 月 | 公共领域 |
| NOAA (多套) | 海平面、海洋热含量 | ERDDAP/CSV | 月 | 公共领域 |
| NASA CNEOS Sentry | NEO 撞击风险表 | JSON API | 日 | 公共领域 |
| USGS 地震流 | M6+ 事件 | GeoJSON API | 实时 | 公共领域 |
| NOAA SWPC | 空间天气警报 | JSON API | 实时 | 公共领域 |

**Tier B — 年度人工录入**（无 API 或许可受限，出版节奏本身就是年度；录入表单 + 双人核对）

| 源 | 内容 | 障碍 |
|---|---|---|
| SIPRI 年鉴 / FAS | 核弹头数量 | PDF 出版物 |
| 末日时钟 | 距午夜秒数 | 年度新闻稿 |
| UN WPP | 人口结构 | 两年一版，文件大 |
| IUCN 红色名录汇总数 | 受威胁物种比例 | API 需申请、许可限制再分发 |
| WWF/ZSL LPI | 生命力指数 | 两年一版报告 |
| GCF / GCRI 年报 | 风险排序 | 报告文本 |

**Tier C — 静态文献常数**（不"更新"，只随文献修订）：Ord 存在风险概率表、VEI-8 复现周期、太阳演化时间表、卡灵顿事件概率区间、级联边表。每条带完整引用（作者、年份、DOI）。

前端溯源弹层显示档位徽标：`实时` / `年度录入` / `文献常数`——让用户一眼看出哪些数字是"活的"。这本身是不确定性教育的一部分。

## 2. 快照 Schema

单一 JSON 快照 = 一次指数计算的完整输入与输出，版本化保存（`snapshots/hsci-2026.json`），历史快照序列即"HSCI 年度曲线"研究资产。

```jsonc
{
  "schema_version": "0.1",
  "snapshot_id": "hsci-2026",
  "computed_at": "2026-07-30T00:00:00Z",
  "methodology_version": "0.1",        // 关联方法学 changelog
  "indicators": [{
    "id": "c1_co2_ppm",
    "domain": "C1",
    "value": 427.6,
    "unit": "ppm",
    "normalized": 62.4,                 // 三锚点归一化结果
    "anchors": [280, 450, 550],
    "tier": "A",
    "uncertainty": 1,                   // 1 实测 / 2 模型 / 3 判断
    "source": { "name": "Scripps CO2 Program", "url": "…", "license": "CC BY", "retrieved_at": "2026-07-01" }
  }],
  "cells": [{                           // 46 个有效格
    "domain": "C1", "horizon": "T0",
    "P": 0.9, "I": 2, "U": 1, "R": 47.2,
    "note": "升温突破1.5°C几乎锁定；30年内为区域级危机烈度",
    "refs": ["IPCC AR6 WGI SPM"]
  }],
  "domain_scores": [{ "domain": "C1", "S_A": 41.0, "S_E": 55.0 }],
  "composite": {
    "HSCI_A": 38.2, "HSCI_A_band": "yellow",
    "HSCI_E": 61.5, "HSCI_E_band": "orange",
    "sensitivity_5_95": [31.0, 46.5],   // 权重重采样区间
    "top_drivers": ["C9", "C3", "C1"]
  }
}
```

## 3. 级联边表（V6 数据基础）

```jsonc
{ "edges": [{
    "from": "C1", "to": "C5",
    "mechanism": "升温→农业带迁移→粮食短缺→冲突与移民",
    "strength": 3,                      // 1 弱 / 2 中 / 3 强（文献编码）
    "refs": ["IPCC AR6 WGII Ch.16", "Richards et al. 2021"]
}]}
```

初版目标 ~20 条边，全部人工文献编码。桑基图边宽 = strength，点击边显示机制描述与引用。

## 4. 管线运行与降级

- 架构：静态站点 + 定时任务（GitHub Actions cron 即可，无需常驻后端）：抓取 Tier A → 校验（类型、范围、与上期偏差 >3σ 报警）→ 归一化 → 重算指数 → 提交新快照 → 站点重新构建。
- 任一源抓取失败：沿用该指标上一次值，`retrieved_at` 不变，前端自动显示"数据截至 X 日"徽标。**绝不静默展示过期数据，也绝不因单源失败阻塞整体更新。**
- Tier B 录入走 PR 流程：录入表单生成 JSON diff，双人核对合并——录入历史即审计日志。

## 5. Phase 1 实施顺序

1. 定 schema（本文 §2）并手工构造首个快照（Tier B/C 数据 + 46 格 P/I/U 初评）；
2. 接入 3 个最容易的 Tier A 源（Scripps、GISTEMP、CNEOS）跑通自动管线；
3. 权重敏感性分析脚本；
4. 方法学页 + changelog 机制上线；
5. 其余 Tier A 源逐个接入。
